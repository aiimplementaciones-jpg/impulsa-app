## 3. SCRIPT AUTOMATIZADO DE ENSAMBLADO (FFMPEG)
Para montar cada guión automáticamente con su cartela oficial en cuanto tengas los clips grabados o renderizados:

```bash
# Ejemplo: Ensamblado de Guion 02 aplicando la cartela en el Gancho
ffmpeg -i "Gancho 02.mp4" -i "overlay_gancho_02.png" -filter_complex "[0:v][1:v]overlay=0:0" -c:a copy "Gancho_02_Overlay.mp4"

# Concatenar las 4 partes en el Video Máster final
ffmpeg -f concat -safe 0 -i list_g02.txt -c copy "Guion_02_Master.mp4"
```
